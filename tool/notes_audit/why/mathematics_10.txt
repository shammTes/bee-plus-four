math10-u1-q01|Every function is a relation (a set of ordered pairs), but a relation is a function only if no input x is paired with two different outputs. Example: {(1, 2), (2, 2)} is a function; {(1, 2), (1, 3)} is not.
math10-u1-q02|The domain is the set of first coordinates: here only 1 appears, so the domain is {1}. Because 1 goes to both 2 and 3, the relation is not a function.
math10-u1-q03|A vertical line is a set of points with the same x. If it meets the graph twice, that x has two y-values, so the graph is not a function.
math10-u1-q05|Division by zero is undefined, so the denominator x − 4 must not be 0. Domain: all real numbers except 4, i.e. x ≠ 4.
math10-u1-q06|A real square root needs a non-negative number inside: x − 2 ≥ 0, so x ≥ 2. Domain: [2, ∞).
math10-u1-q07|Each x gives exactly one value x², so y = x² is a function. It is not one-to-one because two inputs give the same output, e.g. 2² = (−2)² = 4.
math10-u1-q08|A horizontal line has one y-value. If it meets the graph twice, two different x have the same y, so the function is not one-to-one and its inverse would not be a function.
math10-u1-q09|Step 1: swap x and y: x = 2y + 1. Step 2: solve for y: 2y = x − 1, y = (x − 1)/2. Check: f(f⁻¹(x)) = 2·(x − 1)/2 + 1 = x ✔.
math10-u1-q10|The inverse swaps every point (a, b) to (b, a), which is the reflection in the line y = x. So the graphs of f and f⁻¹ are mirror images in y = x.
math10-u1-q11|f(x) = x³ is strictly increasing, so it is one-to-one on ℝ. Swap and solve: x = y³ gives y = ∛x, so f⁻¹(x) = ∛x.
math10-u1-q12|f and f⁻¹ undo each other: f⁻¹ sends 5 to some a with f(a) = 5, then f sends a back to 5. So f(f⁻¹(5)) = 5.
math10-u1-q13|In an ordered pair (x, y) the first entry is the input (from the domain) and the second is the output (in the range); order matters, (2, 5) ≠ (5, 2).
math10-u1-q14|A square is never negative, and every non-negative number is a square (e.g. 9 = 3²). So the range is all y ≥ 0, written [0, ∞).
math10-u1-q15|On ℝ, each y > 0 comes from two inputs (x and −x), so x² is not one-to-one. Keeping only x ≥ 0 leaves one input for each y, and then f⁻¹(x) = √x.
math10-u1-q16|Every x gives the same output 5, so it is a function. All inputs share one output, so it is not one-to-one and has no inverse function (its graph fails the horizontal-line test).
math10-u1-q17|f⁻¹ reverses f: since f(2) = 7, f⁻¹(7) = 2. One-to-one guarantees 2 is the only input with output 7.
math10-u1-q18|y = x rises 1 unit for every 1 unit to the right, so its slope is 1. It is the mirror line between a function and its inverse.
math10-u1-q19|A set of pairs fails to be a function when one first entry has two different second entries, e.g. (3, 1) and (3, 4).
math10-u1-q20|F = (9/5)C + 32 converts Celsius to Fahrenheit; its inverse C = (5/9)(F − 32) converts back. Both are linear, one-to-one functions, so each undoes the other.
math10-u1-q21|Definition: a function assigns exactly one output to each input. A relation where some x has two y-values (option A) is not a function.
math10-u1-q22|SSS (three pairs of equal sides) proves two triangles are congruent, i.e. the same shape and size. Similarity uses equal angles or proportional sides.
math10-u2-q01|A geometric system is built in layers: undefined terms (point, line, plane), then definitions and axioms (accepted statements), then theorems proved from them.
math10-u2-q02|A conjecture is a statement that seems true from examples or patterns but has not yet been proved; it becomes a theorem only after a proof.
math10-u2-q03|A general claim says "for all"; one case where it is false (a counter-example) shows the claim is not always true. Example: "all primes are odd" is false because of 2.
math10-u2-q04|Drawings can be misleading (lines may look parallel or equal). Marking the given equal sides, angles and parallels makes sure every step of the proof uses only given facts.
math10-u2-q05|When two lines cross, the opposite angles are equal because each one together with the same neighbouring angle makes 180° (a straight line).
math10-u2-q06|When a transversal cuts two parallel lines, alternate angles (on opposite sides of the transversal, between the parallels, a "Z" shape) are equal.
math10-u2-q07|Co-interior angles lie on the same side of the transversal between the parallels (a "C"/"U" shape); they add up to 180°.
math10-u2-q08|Corresponding angles are in matching positions at each intersection (an "F" shape); with parallel lines they are equal.
math10-u2-q09|A definition fixes the exact meaning of a word, e.g. "a midpoint divides a segment into two equal parts", so everyone uses the same meaning in a proof.
math10-u2-q10|A picture shows one case and may suggest a result; a proof uses definitions, axioms and earlier theorems to show it is true in every case.
math10-u2-q11|A regular polygon is both equilateral (all sides equal) and equiangular (all angles equal), e.g. an equilateral triangle or a square. A rhombus is not regular unless its angles are 90°.
math10-u2-q12|In a convex figure no interior angle exceeds 180°, so the segment joining any two of its points lies completely inside it. A "dented" (concave) polygon fails this.
math10-u2-q14|Parallel lines lie in the same plane and never meet however far they are extended; they have the same direction (equal slopes).
math10-u2-q15|The midpoint M of AB lies on AB with AM = MB, so it divides the segment into two equal lengths.
math10-u2-q16|An angle bisector is a ray from the vertex that divides the angle into two equal angles, each half of the original.
math10-u2-q17|The "given" lists the facts we start from. Writing them first makes clear what may be used, and the proof then moves step by step to what is to be proved.
math10-u2-q19|An axiom (postulate) is accepted without proof; a theorem is a statement proved using axioms, definitions and earlier theorems.
math10-u2-q20|Given AB = AC, draw the bisector of angle A to meet BC at D. Triangles ABD and ACD are congruent (SAS: AB = AC, equal angles at A, common side AD), so ∠B = ∠C. It shows the "given, construction, reason" pattern.
math10-u3-q01|A polygon with n sides can be cut into (n − 2) triangles from one vertex, each 180°. For n = 6: (6 − 2) × 180° = 720°.
math10-u3-q02|Interior sum of a pentagon = (5 − 2) × 180° = 540°. A regular pentagon has 5 equal angles: 540° ÷ 5 = 108°.
math10-u3-q03|Walking around a convex polygon you turn through each exterior angle once and end facing your starting direction: one full turn, 360°, whatever the number of sides.
math10-u3-q04|The 8 exterior angles are equal and add up to 360°, so each is 360° ÷ 8 = 45° (and each interior angle is 180° − 45° = 135°).
math10-u3-q05|The exterior angle and the adjacent interior angle make 180°, and so do the three interior angles; therefore the exterior angle equals the sum of the two opposite (remote) interior angles.
math10-u3-q07|The angle subtended by an arc at the centre is twice the angle it subtends at any point on the remaining circumference, e.g. 80° at the centre gives 40° at the circumference.
math10-u3-q08|In a cyclic quadrilateral (all four vertices on a circle) opposite angles are supplementary: ∠A + ∠C = ∠B + ∠D = 180°.
math10-u3-q09|A tangent touches the circle at one point and the radius drawn to that point meets the tangent at 90°.
math10-u3-q10|From an external point P the two tangent segments PA and PB are equal, because triangles OAP and OBP are congruent right triangles (RHS: common OP, OA = OB).
math10-u3-q11|Angles at the circumference standing on the same arc (in the same segment) are equal, since each is half of the same central angle.
math10-u3-q12|If chords AB and CD meet at E inside the circle, then AE × EB = CE × ED. Example: AE = 4, EB = 3, CE = 2 gives ED = 12 ÷ 2 = 6.
math10-u3-q14|(3 − 2) × 180° = 180°: the formula agrees with the angle sum of a triangle, a good check of the rule.
math10-u3-q15|Only in a regular polygon are all interior (or exterior) angles equal, so only then can you divide the total by n to get one angle.
math10-u3-q16|In a convex polygon all exterior angles turn in the same direction, so together they make exactly one full turn (360°). A concave polygon has a reflex interior angle and the simple rule breaks.
math10-u3-q17|From an external point P, the radii OA and OB are perpendicular to the tangents. Triangles OAP and OBP are congruent (RHS), so PA = PB and triangle APB is isosceles.
math10-u3-q19|If a quadrilateral's opposite angles do not add up to 180°, it cannot be cyclic (its vertices do not all lie on one circle). Example: a rhombus with angles 60° and 120° — opposite angles 60° + 60° ≠ 180°.
math10-u3-q20|Exterior angle = sum of the two remote interior angles: 110° = 50° + x, so x = 60°.
math10-u3-q21|(5 − 2) × 180° = 3 × 180° = 540°. 360° is a quadrilateral and 180° a triangle.

math10-u5-q01|Congruent figures have exactly the same shape and size; one can be placed exactly on the other (possibly after a reflection).
math10-u5-q02|SSS: if three sides of one triangle equal three sides of another, the triangles are congruent.
math10-u5-q03|SAS: two sides and the angle between them (the included angle) are equal in both triangles.
math10-u5-q04|ASA: two angles and the side between them are equal. (AAS also works, because the third angles are then equal too.)
math10-u5-q05|RHS works only for right-angled triangles: equal hypotenuses and one other equal side. Pythagoras then makes the third sides equal as well.
math10-u5-q06|Equal angles fix the shape but not the size: a small and a large equilateral triangle have equal angles but are not congruent (they are similar).
math10-u5-q07|With two sides and a non-included angle, the third side can sometimes swing to two different positions, giving two different triangles, so SSA does not prove congruence.
math10-u5-q08|In △ABC ≅ △PQR the order shows the matching: A ↔ P, B ↔ Q, C ↔ R, so AB = PQ, ∠B = ∠Q, and so on.
math10-u5-q09|Once triangles are proved congruent, all their corresponding sides and angles are equal ("corresponding parts of congruent triangles are equal", CPCT).
math10-u5-q10|A side shared by both triangles is equal to itself, so it gives one pair of equal sides for free; write "common side" as the reason.
math10-u5-q11|Mark the equal legs (AB = AC) and use the common side or the angle bisector; this usually completes SAS or ASA, from which the base angles are equal.
math10-u5-q12|Congruent shapes have equal corresponding sides, so the sums of their sides, the perimeters, are equal.
math10-u5-q13|Congruent shapes fit exactly on top of each other, so they cover the same area.
math10-u5-q14|A reflection keeps all lengths and angles, so the image is congruent; only the orientation is reversed (as in a mirror).
math10-u5-q16|The included angle is the angle formed by the two named sides at their common vertex, e.g. for sides AB and AC it is ∠A.
math10-u5-q17|The included side is the side joining the vertices of the two named angles, e.g. for ∠A and ∠B it is AB.
math10-u5-q18|Equal numbers of tick marks show sides that are given equal; equal arcs show equal angles. They tell you which facts you may use.
math10-u5-q19|A proof must use given facts, definitions and theorems. Appearance is not a reason, because drawings are not exact.
math10-u5-q20|Congruence tests (SSS, SAS, ASA, RHS) are theorems; inside a proof you quote one of them as the reason that two triangles are congruent.
