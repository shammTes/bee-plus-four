TITLE: Domain and range of square-root functions
S: Write the function in the form f(x) = a√(bx + c) + d. | Domain: the expression under the root must be non-negative, so solve bx + c ≥ 0. | Range: √(…) ≥ 0, so if a > 0 then f(x) ≥ d; if a < 0 then f(x) ≤ d. | The starting point of the graph is where bx + c = 0, at height d. | Check with one extra point inside the domain to see the direction of the curve.
E: f(x) = −2√(x + 1) + 5. Domain: x + 1 ≥ 0 → x ≥ −1. Start point (−1, 5). Since a = −2 < 0 the curve goes down from 5, so the range is y ≤ 5. Check x = 3: f(3) = −2(2) + 5 = 1 ≤ 5 ✓.
M: "Inside ≥ 0 for the Domain; Start height d for the Range" — I-D, S-R.
T: Write domain and range in interval notation: [−1, ∞) and (−∞, 5] – square brackets because the endpoints are included.
