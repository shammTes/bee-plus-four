C: The vertex of the parabola y = x² − 4x + 3 is:
O: *(2, −1) | (−2, 15) | (4, 3) | (2, 3)
W: For y = ax² + bx + c the vertex x-coordinate is x = −b ÷ 2a = 4 ÷ 2 = 2. | Substitute: y = 2² − 4(2) + 3 = 4 − 8 + 3 = −1. | Answer: vertex (2, −1). | Tip: a = 1 > 0, so the parabola opens upward and the vertex is a minimum point.

@lesson math11-u2-l2-2
C: The domain of f(x) = √(x − 3) is:
O: *x ≥ 3 | x > 3 | x ≤ 3 | all real numbers
W: The expression under a square root must not be negative: x − 3 ≥ 0. | Solve: x ≥ 3. | Answer: domain = [3, ∞). | Tip: The range of √(x − 3) is y ≥ 0, because a principal square root is never negative.

@lesson math11-u2-l2-4
C: The inverse of f(x) = √x + 2 (x ≥ 0) is:
O: *f⁻¹(x) = (x − 2)², x ≥ 2 | f⁻¹(x) = x² + 2 | f⁻¹(x) = √(x − 2) | f⁻¹(x) = (x + 2)², x ≥ 0
W: Write y = √x + 2 and swap x and y: x = √y + 2. | Solve for y: √y = x − 2 → y = (x − 2)². | The domain of the inverse is the range of f: x ≥ 2. | Tip: Always state the restricted domain of the inverse of a square-root function.
