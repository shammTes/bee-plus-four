FourLock — lock papers for 4 (Mac)

Needs: Python 3 (preinstalled on macOS) and optionally `brew install qpdf`.

Double-click FourLock.app. It asks you to:
  1. Pick a PDF or a 4 exam JSON
  2. Type a password
  3. Choose Lock PDF, Pack exam JSON (.fourpack), or Unlock

Locked PDF  →  name.locked.pdf   (or name.pdf.fourpdf if qpdf is missing)
Packed exam →  name.fourpack     (AES-256; unlock on the Mac, then copy JSON into 4 Model exams)

4 on the phone does not render PDFs. Use Pack for exam JSON that 4 already understands.
